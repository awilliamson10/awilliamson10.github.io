This is a sample blog post to demonstrate how your new blog works. You can write your posts in Markdown and they'll be automatically rendered.

## Features

- Clean, minimal design inspired by modern blogs
- Markdown support for easy writing
- Automatic reading time calculation
- Responsive design that works on all devices
- RSS feed support

## Writing Posts

To add a new post, simply create a new `.md` file in the `_posts` directory with the following naming format:

```
YYYY-MM-DD-title.md
```

Then add front matter at the top:

```yaml
---
title: Your Post Title
date: YYYY-MM-DD
---
```

Happy blogging!
